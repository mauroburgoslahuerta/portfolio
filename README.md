# Mauro Burgos - Portfolio EdTech

Portfolio personal y profesional de Mauro Burgos Lahuerta, Diseñador Pedagógico y Creador EdTech.

## Sobre este proyecto

Este repositorio contiene el código fuente de mi portfolio interactivo. Está diseñado para reflejar mi perfil híbrido: docente con experiencia en aula e inclusión digital, y desarrollador de soluciones EdTech con Inteligencia Artificial.

🔗 **[Visitar Portfolio Interactivo](https://mauroburgoslahuerta.github.io/portfolio/)**

## Arquitectura y Tecnologías

El portfolio es un proyecto front-end estático optimizado para el rendimiento y la mantenibilidad:

- **Estructura:** HTML5 Semántico.
- **Estilos:** CSS3 nativo (Vanilla CSS) utilizando variables globales (Custom Properties) para consistencia en el diseño, animaciones suaves y un layout *responsive*.
- **Interactividad:** JavaScript (Vanilla JS) para gestionar el sistema de filtrado de proyectos, el efecto de máquina de escribir y la renderización dinámica de modales.
- **Gestión de Datos:** Inyección dinámica de contenido en los modales mediante una estructura de datos JSON, lo que permite una actualización limpia del contenido de los proyectos.
- **Despliegue:** GitHub Pages.

## Estructura del Repositorio

- `/assets`: Imágenes optimizadas, previsualizaciones de proyectos y Currículum Vitae.
- `/css`: Estilos, variables del sistema de diseño y *media queries*.
- `/js`: Lógica principal del front-end (`script.js`).
- `index.html`: Punto de entrada de la aplicación.
