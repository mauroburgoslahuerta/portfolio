# Mauro Burgos - Portfolio EdTech

Docente (Educación Primaria) + Desarrollador EdTech. Construyo la herramienta y sé cómo enseñarla.

## Sobre este proyecto

Este repositorio contiene el código fuente de mi portfolio interactivo. Está diseñado para reflejar mi perfil híbrido: docente con experiencia en aula e inclusión digital, y desarrollador de soluciones EdTech con Inteligencia Artificial.

🔗 **[Visitar Portfolio Interactivo](https://mauroburgoslahuerta.github.io/portfolio/)**

## Propuesta de Valor

Mi perfil profesional se fundamenta en tres líneas de acción:
- **Docencia y Aula:** Experiencia impartiendo Robótica y Programación, fomentando el pensamiento computacional en el entorno escolar mediante herramientas como Scratch y Makecode.
- **Alfabetización Digital:** Formación práctica para reducir la brecha digital, dotando de autonomía y herramientas de uso diario a poblaciones en entornos rurales.
- **Desarrollo EdTech:** Creación de herramientas digitales interactivas utilizando Inteligencia Artificial para resolver problemas reales y facilitar el trabajo docente.

## Proyectos Destacados

- **AventurIA:** Plataforma de desarrollo propio que transforma cualquier tema en una aventura educativa interactiva. Ajusta dinámicamente lenguaje y dificultad sin perder el enfoque pedagógico ni el control consciente humano.
- **Pensamiento Computacional en el Aula:** Diseño instruccional de proyectos gamificados (Scratch, Arcade Makecode) para el desarrollo de la lógica y la resolución creativa de problemas en Educación Primaria.

*Puedes explorar todos los proyectos interactivos directamente en la [web del portfolio](https://mauroburgoslahuerta.github.io/portfolio/).*

## Arquitectura y Tecnologías

El portfolio es un proyecto front-end estático optimizado para el rendimiento y la mantenibilidad:

- **Estructura:** HTML5 Semántico.
- **Estilos:** CSS3 nativo (Vanilla CSS) utilizando variables globales para consistencia y animaciones fluidas.
- **Interactividad & Datos:** JavaScript (Vanilla JS) y estructuración JSON para la inyección dinámica multi-idioma de los proyectos en modales.
- **Despliegue:** GitHub Pages.
